## Database

In schema.ts, add the schema for an event

1. name
2. location
3. image
4. text field for date time like "Starts at 4 Apr 2025, 10am" or "5 Apr 206 to 8 Apr 2025, 10am-8pm daily"
5. link

In convex folder, add a events.ts containing get, create, update and delete methods.

## View

Add a route admin/events which shows a table containing list of events and a create button.

When click on the event name, show the fields as editable and save button.
